# Contributing to Benchmarking Project — Summer 2025

Thank you for considering contributing! We welcome pull requests, bug reports, and feature suggestions.

## How to Contribute
1. **Fork the repository** and create your branch from `Develop`.
2. **Write clear, concise commit messages.**
3. **Test your code** before submitting a pull request.
4. **Open a pull request** with a clear description of your changes.
5. **Participate in code review** and address feedback.

## Code Style
- Follow PEP8 for Python code.
- Use `black` for formatting and `pytest` for testing.
- Document functions and modules with clear docstrings.

## Reporting Issues
- Use [GitHub Issues](https://github.com/rwandantechy/benchmarking-project-summer-2025/issues) for bugs or feature requests.
- Include steps to reproduce, expected behavior, and screenshots/logs if relevant.

## Community
- Be respectful and inclusive.
- See the [Code of Conduct](CODE_OF_CONDUCT.md) (if available).
