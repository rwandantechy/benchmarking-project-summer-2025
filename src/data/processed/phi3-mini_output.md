Machine Learning can be broadly classified into two categories: Supervised Machine Learning and Unsupervised Machine Learning. Here are their key differences along with examples for both types.

Supervised Machine Learning involves using labeled data (data that is tagged or annotated) to teach the model how to predict outcomes accurately on unseen, new datasets. It learns a function that maps input to an output based on example inputs and their corresponding outputs. The objective of supervised learning algorithms is to approximate the underlying continuous distribution from which samples are drawn as closely as possible.

Example: Consider training a model for spam detection using labeled emails where 'spam' or 'non-spam' labels have been assigned by human experts based on their personal experience and intuition about what constitutes an email being considered either of these categories, hence this is Supervised Learning task. The goal here would be to build a model that can accurately label new incoming emails as spam or non-spam with high precision using the labeled dataset for training.

Unsupervised Machine Learning involves finding patterns and relationships in data without any prior knowledge of what these might be, i.e., we are not given pre-defined labels to train our model on like Supervised learning. Instead here the goal is often clustering or dimensionality reduction techniques which helps find inherent structures within such datasets for exploring unknown domains where little information about data and no clear objective function exists that defines how good of a solution it might be in terms of predicting outcomes accurately with unseen, new datasets like anomaly detection.

Example: Consider the task of customer segmentation using K-Means Clustering algorithm on an eCommerce website where we have users' age and spending data but no predefined labels or categories for them (e.g., 'Teenager', 'Adults'). Our goal is to group customers into clusters based purely on their similar behaviors, such as purchasing patterns in the absence of any prior knowledge about these groups beforehand making it an Unsupervised Learning task.

So essentially Supervised learning algorithms learn from previous examples and make predictions or decisions without human intervention while unsupervised ML works with only input data to find underlying structures or distribution, like clustering where we are looking for patterns that can help us understand how similar the points in a dataset might be to each other.
