Supervised Machine Learning is a type of ML wherein we feed data that already has labels to train our model on predicting future outputs based on this labelled input using regression or classification techniques. In essence, it’d be as if you are training the algorithm with your labeled dataset and letting them learn from their mistakes by giving rewards/punishments accordingly until they get closer results towards optimal solution for a problem at hand; think of these algorithms like personal trainers who help us perform better when doing certain tasks (like playing sports) because we provide feedback based on our performance.
Example: Let's say you want to predict housing prices in New York City, and your dataset has properties with their selling price as well along with features such as number of bedrooms/bathrooms etc., This is a regression problem where supervised learning algorithms like linear regression or decision trees can be used. 
On the other hand Unsupervised Machine Learning doesn't require any labels on our input data and instead finds patterns within it by trying to group similar items into clusters using techniques such as K-Means clustering, Apriori algorithm etc; this is akin when you go shopping for clothes without prior knowledge of sizes/fit but still manage somehow finding right clothing based just off how they look.
Example: Let's say we have dataset containing customer’s spending behaviour in different categories e.g groceries, electronics or fashion etc.; clustering algorithms like K-Means can be used here to identify groups of customers with similar buying habits without prior knowledge about their preferences/tastes beforehand; this helps marketers target these customer segments better based on shared behavior traits rather than demographics alone.
In summary, Supervised ML requires labeled input data for training while Unsupervised does not and instead finds patterns within given dataset through clustering or association techniques without prior knowledge about underlying relationships/interactions between items being analyzed beforehand - both approaches have their own unique strengths & weaknesses depending on specific use cases where one might prove more suitable over other based upon requirements at hand .
