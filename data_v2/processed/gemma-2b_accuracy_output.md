## q1
**Prompt:**

```
Solve the quadratic equation x^2 - 7x + 12 = 0. List all real or complex roots.
```

**Model Answer:**

```
$$x^2 - 7x + 12 = 0$$

$$(x - 3)(x - 4) = 0$$

Setting each factor to zero, we get:

$$x - 3 = 0$$  or  $$x - 4 = 0$$

$$x = 3$$  or  $$x = 4$$

These are the only real roots.

Therefore, the solutions are x = 3 and x = 4.
```

**Correct:** True
