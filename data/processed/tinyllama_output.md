Supervised machine learning (SML) is a well-established technique for predicting outcomes based on observed data. The process involves collecting labeled data (known as "training" or "classification") with true labelled and unlabeled samples, and using the training data to train a model that predicts the true label of new samples.

Unsupervised machine learning (UML), in contrast, is a more exploratory approach that aims to find hidden patterns, structures, or relationships between observed data without assuming any prior knowledge about its structure. UML techniques aim to analyze the data without imposing specific constraints or assumptions on the data, making them less sensitive to outliers and noise.

Here are some examples of how each type of machine learning is used:

1. Supervised Machine Learning (SML): Consider a dataset with two classes of objects ("dog" vs "cat"), where each object has multiple features. In SML, the goal is to predict which class an unseen object belongs to based on its features.
 
The training data includes labeled data where the true label of each new object is known (e.g., a dog or cat). In UML, we aim to identify patterns or structures in the data that could explain the classification and find patterns that can be used to predict new objects.

2. Unsupervised Machine Learning (UML): Consider a dataset with only observed features (i.e., no labels). In UML, the goal is to discover hidden structure or relationships between features that might not have any inherent relationship with the other features.

The training data includes labeled data where the true label of each new object is unknown (or unlabeled), and we aim to identify patterns or structures in the data that can be used to predict new objects.

In both SML and UML, these techniques can be applied in various scenarios such as image classification, text classification, drug discovery, financial risk analysis, and many more.
