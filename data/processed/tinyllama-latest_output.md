Supervised Machine Learning (SML):
- Training data is labeled with labels or classifications that correspond to each instance in the dataset.
- Each new input data point belongs to a single label/class.
- During training, SML calculates and assigns labels to instances based on their characteristics (features), which helps it generalize well for unseen or new inputs.
- SML works with pre-defined labels as the training set is labeled. It does not require any labeled data during model building or prediction phase.

Unsupervised Machine Learning (UML):
- The goal of UML is to find hidden structures or patterns in unlabeled data that are not directly visible in the input data.
- The key idea is to use the properties and relationships between the features in the dataset rather than relying on label information, which is assumed or known during training.
- Unlike SML, UML does not assign any labels/classes to unseen inputs, as it is working with unlabeled data. 

An example of supervised learning is a machine learning model that learns from labeled data (with class labels) and can make predictions or recommendations based on this input data. In contrast, an example of UML is a machine learning algorithm that uses unlabeled data to identify patterns or relationships in the feature space that are not directly visible in the training set. The goal of UML is to improve generalization ability by providing insights into unseen inputs.
