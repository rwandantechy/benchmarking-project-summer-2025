Machine Learning can be broadly categorized into two types: Supervised and Unsupervised learning. Here are their primary distininflences along with examples for a better understanding:

1) **Supervised Machine Learning** involves providing the machine with labeled data, where it learns to predict outcomes based on input features using this training set of known answers (or labels). The main goal here is prediction. A simple and common example would be Linear Regression used for house price estimation or a Decision Tree algorithm in categorization tasks like spam detection (spam/not-spam emails) where the machine learns to classify new inputs based on past data.
    Example: Predicting Housing Prices - A dataset with features such as size, location, number of rooms etc., and known housing prices is provided as labeled training data for a regression model like Linear Regression or Decision Trees which learns to predict the house price based on these inputs.
   
2) **Unsupervised Machine Learning** does not require labelled datasets. It identifies patterns, structures, relationships within given input without any guidance (i.e., it doesn't have a predefined target variable). The goal here is often exploratory and to find hidden insights in data or reduce the dimensionality of complex data sets. Clustering Algorithms are common examples used for tasks like customer segmentation, anomaly detection etc.
    Example: Market Segmentation - A dataset without any predefined labels about customers' purchasing behavior can be analyzed using clustering algorithms to group similar buyers together based on their buying history and demographics; these groups (or clusters) represent different segments of the customer base, identifying common patterns or tendencies within them.

Both methods have extensive applications across a variety of industries from finance, healthcare, retail, to self-driving cars etc., depending on whether your goal is prediction or uncovering hidden insights in data respectively.
