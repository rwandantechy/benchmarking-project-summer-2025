Supervised Machine Learning: Supervised ML is a type of algorithm that learns patterns in data through labeled examples provided by human experts to train it for making predictions or decisions without explicit instructions on how the output should be generated. The main difference between supervised and unsupervised learning lies in this aspect where, with supervised learning algorithms learn from known/labeled dataset which include both input-output pairs while unsupervised machine learning learns only inputs (i.e., patterns or structures within a given dataset without predefined labels).
Example: A common example of Supervised Machine Learning is classification problems such as email spam detection where the model would learn from labeled emails that are either "spam" or "not-spam". Once trained, it can predict whether new incoming emails should be classified into one category (i.e., if they're likely to contain unsolicited advertisements). 

Unsupervised Machine Learning: Unsupervised ML is a type of machine learning that deals with data sets without predefined labels and uses its own internal mechanisms for grouping, clustering or identifying patterns within the dataset. The major difference between supervised and unsupervised learning here lies in their approach to handle input-output pairs wherein while SLM relies on labeled output from prior knowledge/experts, UMLL works without any labels present at all; it discovers structures such as clusters or associations within the data.
Example: A common example of Unsupervised Machine Learning is a Market Basket Analysis (also known as Association Rule Mining), where retailers can analyze customer transactions to identify items that are frequently bought together but not labeled in advance, and discover insights like "Customers who buy apples also tend to purchase granulated sugar." 

Follow-up questions:
1. Can you explain the difference between semi-supervised learning and reinforcement learning?  
Answers: Semi-Supervised Learning is a hybrid approach that combines aspects of both supervised (using labeled data) as well as unsupervised machine learning to make predictions using only partially labeled datasets. Reinforcement Learning, on the other hand, involves training algorithms by rewarding desired outcomes and penalizing undesired ones based on their performance in a specific environment or task without explicit prior knowledge of correct outputs/answers beforehand - it’s more about making decisions that lead to maximized rewards.
2. What are the different types within supervised learning?  
Answers: Supervised Learning can be categorized into two main types, namely Classification and Regression tasks. In classification problems like email spam detection or medical diagnoses from patient symptoms mentioned earlier in this text, machine learning models predict discrete labels (i.e., "spam"/"not-spam", "sick"/"healthy"). On the other hand, regression tasks involve continuous output values - for instance, estimating house prices based on factors like location and square footage fall under Regression problems in Supervised Learning category where machine learning models predict a real number as an output.
