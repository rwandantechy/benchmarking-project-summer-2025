Supervised and unsupervised are two major types of Machine Learning algorithms that differ based on their approach towards data analysis:

1) Supervised Learning - In this type, we have labeled dataset where the target variable is known beforehand along with other features or variables in a structured format. The goal here is to predict these labels for new unseen datasets using patterns learned from training set of supervised learning algorithm by minimizing error rate (misclassification) between predicted and actual label values. 

   Example: A simple example would be spam detection, where an email's content will serve as features while the presence or absence of 'spam' is the target variable that we want to predict for new emails using a supervised machine learning algorithm like Support Vector Machines (SVM) or Naive Bayes classifier.
   
2) Unsupervised Learning - In this type, our dataset does not have any predefined labels and it just consists of features without knowing target variables upfront. The main aim here is to understand the underlying patterns in data by grouping them together based on similarity measures (clustering), discovering hidden structure or summarizing key characteristics present within a large set of unlabelled data(reducing dimensionality using methods like PCA).
   
   Example: A common example would be market segmentation where customers are grouped into different clusters according to their shopping behavior without knowing who belongs which cluster beforehand. An algorithm such as K-means clustering can accomplish this task effectively in supervised learning contexts when we have prior knowledge of the target variable(e.g, age or income group).
   
In summary: Supervised learning algorithms learn from labeled training data and make predictions based on that information while unsupervised machine learning aims to find patterns within given datasets without any labels provided beforehand in order to classify/cluster similar observations together into homogeneous groups.
