Supervised Machine Learning is a type of algorithm that learns from labeled data to predict or classify new data based on past observations. It requires inputting both features (input variables) and labels into the model during its training phase. The goal is for supervised learning algorithms to map inputs, observe how these mappings relate with outputs in historical datasets, learn this relationship'in a process called 'training',and then apply what it has learned to new data to predict outcomes or classifications (output variables). Supervised ML techniques include linear regression and logistic regression. 

An example of supervised learning is email spam detection where emails are labeled as either "spam" or "not-spam". A machine learning model, trained with this historical data can then learn to recognize patterns in the text that distinguish between these two classes (e.g., specific words and phrases) so it could automatically classify new incoming emails into one of those categories based on their content.

Unsupervised Machine Learning is a type where algorithms are used without labeled input, aiming instead at finding hidden patterns or structures within the data. These types do not predict outcomes but try to categorize the inputs (also known as 'clustering') and reducing dimensions of datasets in preparation for other ML methods such as supervised learning techniques through a process called 'dimensionality reduction'. Unsupervised Machine Learning is often used when labeled examples are expensive, difficult or impossible to label. Techniques include K-means clustering, hierarchical/agglomerative clustering and Principal Component Analysis (PCA).

An example of unsupervised learning would be customer segmentation in a marketing context where the aim is not necessarily predict outcomes but rather discover inherent patterns. By feeding demographic information about customers into an algorithm like K-means, it can group them together based on their similarities without any predefined labels or categories (i.e., age ranges, income levels), and market to each of the segments with targeted campaigns that are more likely to resonate with that specific cluster's characteristics.
