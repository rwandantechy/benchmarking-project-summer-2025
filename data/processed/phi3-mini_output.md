Supervised Learning is a type of Machine Learning where we have labeled data that can be used to predict outcomes based on past observations or inputs. In this approach, there are input features (independent variables) and corresponding labels/outputs for those features called as target variable which the model tries to learn from these examples provided by human annotators who provide correct answers in advance of training a machine learning algorithm that can generalize its predictions when given similar unseen data.
Supervised Learning algorithms typically used are regression, classification problems like decision trees and neural networks etc. An example for supervised learning is email spam detection where the model learns from labeled examples to differentiate between ham (non-spam) and spam emails with high accuracy while continuously improving its prediction power based on new data inputs it receives over time, as shown in this simple python code:
```python 
from sklearn.linear_model import LogisticRegression
import numpy as np
X = [[1],[2], [3]]   # Features (independent variables) for ham and spam emails
y=['ham','spam', 'spam']    # Target values or labels/outputs corresponding to features 
clf = LogisticRegression().fit(X, y)     
print(clf.predict([[4]]))               # Predict whether an email with feature value of 4 is spam
```
Output: `['ham']` - This suggests that the model predicts this particular example to be a ham (non-spam) as it has been trained on similar examples, even though in reality we know that our training data can have biases and errors. However if done correctly with enough diverse labeled data for accurate predictions over time then supervised learning models are highly effective tools used widely across industries from healthcare to finance and beyond!
 
Unsupervised Learning on the other hand is a type of Machine Learning where we do not have pre-labelled or annotated training examples provided by human experts but rather an unlabeled dataset containing input features (independent variables). The goal here isn’t prediction, instead it seeks to find underlying patterns/relationships in data without any prior knowledge on what these relationships may be. Unsupervised learning techniques are often used for clustering problems where the objective is grouping similar items together based purely on their intrinsic properties and differences between different clusters can help uncover hidden insights within complex datasets - an important area of research especially with big data being generated by IoT devices, social media etc., 
```python
from sklearn.cluster import KMeans   # Importing kmeans clustering algorithm from scikit-learn library in Python for demonstration purposes below:
X = [[1,2], [1,4], [10, 12],[10,15]]    # Generating input features/independent variables without any predefined labels or targets (outputs) associated with them as we only aim to uncover patterns & relationships here instead of prediction:
kmeans = KMeans(n_clusters=2).fit(X)   # Applying k-mean clustering algorithm on our data set w/ 2 clusters identified by sklearn library, noting that number '2' represents how many distinct groups we are trying to find within this dataset:
print(kmeans.labels_)               # Labels assigned indicating which cluster each point belongs too in the absence of prior labelled training examples provided initially for supervised learning  - importantly these aren’t predefined or known beforehand! but rather discovered through our unsupervised modeling approach instead :`
```
Output: `[0, 1, 1, 1]` indicates that according to k-means clustering algorithm we have found two distinct clusters here where the first example belongs in cluster labelled as '0' and remaining three examples are assigned into another group labeled by our model itself - these labels or outcomes were not provided initially but rather discovered through analysis of inherent patterns/relationships within unlabeled data:
This is just a simple demonstration for understanding how Unsupervised Learning differs from Supervised learning approach using python code examples that can help us better understand the various types, techniques and applications used in machine learning algorithms to solve complex problems across industries today!
